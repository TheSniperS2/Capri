# Capri para Windows

Descarga **Abrir Capri.pyw** y ábrelo con Python 3.12 en Windows 10 u 11. No necesitas clonar el repositorio ni compilar el código.

La primera apertura prepara las dependencias, los modelos de reconocimiento y las referencias visuales. Después selecciona tu micrófono en Ajustes. Para conversación libre, activa la IA local desde Ajustes.

**Capri.zip** contiene el mismo lanzador, una guía y los módulos de la aplicación para consulta. El código completo de desarrollo está en el repositorio.

Si ya tenías esta distribución de Capri, ciérrala completamente y abre el lanzador nuevo para actualizar. La preparación reutiliza los recursos de `%LOCALAPPDATA%\Capri`.

Se requiere internet para la preparación y la voz natural. Las pruebas automatizadas no garantizan precisión de voz o compatibilidad con cada versión de Spotify. Consulta el README para requisitos, privacidad y límites.
