# Retrato de apagado

Recurso experimental conservado como referencia. El apagado actual no muestra retrato y este archivo ya no se incluye en el paquete de instalación.

Archivo: [`assets/capri-apagado-melancolica-v1.png`](../assets/capri-apagado-melancolica-v1.png).

Creado con la herramienta integrada de generación de imágenes, en modo edición de referencia con fondo transparente, a partir de [`capri-base-hd-v1.png`](../assets/capri-base-hd-v1.png). Ilustración derivada para este proyecto de aficionado; no es un fotograma oficial ni cambia los derechos del personaje. La interferencia y el cierre CRT se dibujan por código, por separado.

## Prompt utilizado

```text
Use case: identity-preserve edit. Asset: a high-resolution transparent PNG portrait for Capri's desktop app shutdown sequence. Edit target/reference: the attached existing Capri artwork. Keep this EXACT recognisable angular cyberpunk character identity: vivid red jagged hair, neon green face/skin panels, large circular blue cybernetic eyes set in black angular eye sockets, dark angular jacket with violet edge accents, same flat graphic/cel shaded sharp black line style. Change her expression to quietly indifferent and a little sad/tired, as if saying a restrained goodbye: relaxed slightly drooping eyelids, understated lowered brows, small closed neutral/downturned angular mouth; NO wide zigzag grin, NO cheerful pose, NO crying or tears. Shoulders relaxed. Composition: upright portrait from head/hair through upper torso, entire head fully inside frame with breathing room, centered and clear silhouette. Keep her recognisable rather than turning her into a generic anime girl. Preserve original design and colours, polished clean edges, no blur. Transparent background, no scenery, no noise, no CRT effects (the application adds those), no text, no borders, no other characters. Final project-bound illustration, portrait aspect ratio.
```
