# Icono de Capri

`assets/capri-icono-v2.png` es el original cuadrado en alta resolución. `assets/capri.ico` contiene versiones de 16, 20, 24, 32, 40, 48, 64, 96, 128 y 256 píxeles por lado para las distintas escalas de Windows.

La composición se creó con la herramienta integrada de generación de imágenes a partir del icono anterior. Se conserva la identidad del personaje y se sustituye el encuadre estrecho por una composición cuadrada, sin estirar el rostro. El PNG original se conserva sin recomprimir ni ampliar; el ICO se exporta a tamaños menores.

Preserve the character's recognizable graphic style. Current icon is a narrow portrait with huge unused side margins: FIX THE COMPOSITION into a balanced square head-and-shoulders portrait, with equal apparent width and height of the icon silhouette. Do NOT horizontally stretch the character. Redraw/refine clean hard angular shapes in high resolution, sharp readable at 32px and 48px. Frame face centrally, both eyes visible and a balanced broad red hair silhouette extending to both sides, shoulders minimally visible. Dark near-black rounded-square tile backing, equal comfortable inset on all four edges, only OUTSIDE the rounded square corners actually transparent. No black side strips, no rectangular portrait inside the tile. No letters, no text, no watermark, no added mouth teeth/fangs, no new character, no external frame, no tiny decorative noise. The square tile should nearly fill the canvas. Hair can have restrained subtle red digital texture but avoid heavy grain that impairs small-icon clarity. Deliver one single square icon image.
